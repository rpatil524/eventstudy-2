## Decisions Made

- **ModelBase receives the three context fields** (not just MarketModel): `execute.R` injects `degenerate_mode`, `event_id`, and `firm_symbol` on every model clone, regardless of model type. Without these fields on the base class, any non-MarketModel model (MarketAdjustedModel, ComparisonPeriodMeanAdjustedModel, etc.) would fail with "cannot add bindings to a locked environment". Adding to ModelBase is the correct fix: it matches the execute.R injection pattern and does not require modifying every subclass.
- **grepl('[firm=<FIRM>]', fixed=TRUE) for pipeline-level warning filter**: The CONTRACT-04 pipeline test wraps `fit_model()` + `calculate_statistics()` in `withCallingHandlers`. Two warnings are emitted for a degenerate firm: (1) the contract handler warning in format `"ModelBase [event_id=N] [firm=FIRM_B]: <condition>"`, (2) a dplyr-wrapped "not fitted" warning from `abnormal_returns()` that echoes group info (also containing "FIRM_B"). Filtering by `fixed=TRUE` string `"[firm=FIRM_B]"` isolates only the contract-handler warning.
- **Zero-variance edge-case test updated**: The old test (`expect_error`) was documenting a crash bug. Wave 1 fixed that crash into a controlled lenient-mode warning. The test is updated to document the correct post-fix behavior (`expect_warning` + `expect_false(is_fitted)`).
