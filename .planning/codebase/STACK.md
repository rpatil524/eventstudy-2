# Technology Stack

**Analysis Date:** 2026-09-02

## Languages

**Primary:**
- R 4.1.0+ - Complete package written in R

## Runtime

**Environment:**
- R runtime (4.1.0 or later required)

**Package Manager:**
- CRAN (Comprehensive R Archive Network)
- Lockfile: `DESCRIPTION` (package dependencies)

## Frameworks

**Core:**
- R6 - Object-oriented programming (R6 classes for EventStudyTask, models, statistics)
- ggplot2 - Static visualization
- plotly - Interactive visualization and plots (AR, CAR, AAR, CAAR visualization with confidence bands)

**Data Manipulation:**
- dplyr - Data transformation pipeline
- tidyr - Data tidying and reshaping
- tibble - Modern data frames
- stringr - String manipulation
- purrr - Functional programming utilities

**Testing:**
- testthat 3.0.0+ - Unit testing framework
  - Configuration: `Config/testthat/edition: 3` in DESCRIPTION
  - Test runner: `tests/testthat.R`

**Build/Dev:**
- roxygen2 7.3.3 - Documentation generation and NAMESPACE management
- knitr - Dynamic report generation (vignettes)
- rmarkdown - R Markdown document support

## Key Dependencies

**Critical (Imports):**
- R6 - Object system for class definitions
- distributional - Distribution objects (Student's t-distribution for test statistics)
- ggplot2, plotly - Visualization framework
- dplyr, tidyr, tibble, purrr, stringr - Data manipulation pipeline
- rlang - Metaprogramming and quoting (`%||%` operator, `.data` pronoun)
- stats - Base statistical functions (lm, Box.test, acf, normality tests, etc.)
- tools, utils - Base R utilities

**Optional but Suggested (Suggests):**
- **Data Download:**
  - tidyquant - Primary stock data source (Yahoo Finance)
  - quantmod - Fallback stock data source (Yahoo Finance)
- **Factor Models:**
  - rugarch - GARCH model fitting
  - rmgarch - Multivariate GARCH (DCC-GARCH models)
  - quadprog - Quadratic programming (synthetic control optimization)
- **Panel Event Studies:**
  - did - Callaway & Sant'Anna estimator
  - DIDmultiplegt - de Chaisemartin & D'Haultfoeuille estimator
  - didimputation - Borusyak, Jaravel & Spiess estimator
- **Export:**
  - openxlsx - Excel export with multi-sheet support
- **Development/Testing:**
  - gridExtra - Grid graphics layout (diagnostic plots)
  - covr - Code coverage analysis
  - zoo - Time series (index handling in quantmod fallback)
  - DT - Interactive data tables (in reports)
  - sandwich - HC-robust standard errors for cross-sectional regression

## Configuration

**Environment:**
- No environment variables required for basic operation
- No secrets/API keys needed (external data sources are public)

**Build:**
- Build configuration: `EventStudy.Rproj` (RStudio project file)
- NAMESPACE auto-generated by roxygen2 from `@export` tags in R files
- R6 object definitions in `R/` files with roxygen documentation

## Platform Requirements

**Development:**
- R 4.1.0 or later
- RStudio recommended (reads `EventStudy.Rproj`)
- devtools package for installation and development workflow

**Production:**
- R 4.1.0 or later
- Optional: tidyquant or quantmod (only if using `download_stock_data()`)
- Optional: rugarch, rmgarch (only if using GARCH/DCC-GARCH models)
- Optional: did, DIDmultiplegt, didimputation (only if using panel event studies)
- Optional: openxlsx (only if exporting to Excel)
